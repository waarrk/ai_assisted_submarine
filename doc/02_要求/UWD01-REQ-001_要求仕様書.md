# 適用範囲

水中ドローン UWD-01 の機械系の設計・開発に対する要求事項を定める．要求事項は 6件である．詳細設計書 UWD01-DDS-001 は，この 6件への適合を示す．

# 要求事項

表: 要求事項 {#tbl:req}

| 番号 | 区分 | 要求事項 | 出所 |
|---|---|---|---|
| R-01 | 機能 | 与圧部の内径 120 mm 以上，長さ 400 mm 以上 | 依頼者の指示 |
| R-02 | 性能 | 設計水深 100 m | 依頼者の確認 |
| R-03 | 性能 | 速度より姿勢制御を優先 | 依頼者の指示 |
| R-04 | 機能 | 物体の把持 | 依頼者の指示 |
| R-05 | 費用 | 市販の安価な水中スラスタの使用 | 依頼者の指示 |
| R-06 | 調達 | 入手性のある市販部品の使用 | 依頼者の指示 |

R-01 の内径は下限であり，搭載する基板の寸法に合わせて拡大してよい．R-02 は設計の途中で依頼者が 100 m と確認した値である．

# 設計上の方針

依頼者が設計の進め方として指示した事項を @tbl:policy に示す．要求事項と同じく設計審査の確認対象とする．

表: 設計上の方針 {#tbl:policy}

| 番号 | 方針 |
|---|---|
| P-01 | 組立状態から設計を開始し，構成ごとにファイルを分けて管理 |
| P-02 | 加工の方法と工程を部品ごとに決定 |
| P-03 | 費用と加工の容易さを考慮 |
| P-04 | 日本産業規格と国内の加工・調達の慣行に適合 |
| P-05 | 購入品は製造元の形状データで干渉を確認 |
| P-06 | 部品表を加工品と購入品の両方で作成 |
| P-07 | 内部の基板は BIRDS 衛星バスの差し込み基板の構成を流用 |
| P-08 | 設計上の危険要因を残さず確認 |

# 対象外

電気回路，制御ソフトウェア，テザー，カメラの選定は対象としない．運用する水域，最高速度，連続運転時間は依頼者から指定を受けていない．
