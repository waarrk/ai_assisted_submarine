## 2. 採用機種: ApisQueen U2 Mini

underwaterthruster.com の商品ページ（2026-11-25 に実ブラウザで確認）による。

| 項目 | 値 |
| --- | --- |
| 電圧 | 12〜16 V（3〜4S LiPo） |
| 推力（16 V） | 仕様表は 2 種類ある。8 A 版: 前進 1.30 kgf・逆転 1.20 kgf。12 A 版: 前進 2.1 kgf・逆転 1.7 kgf |
| 最大電流・出力 | 8 A・130 W（本文）／12 A・192 W（仕様欄） |
| 質量 | 210 g |
| 外形 | 全長 95.8、ダクト外径 72.21・内径 65.11・長さ 36.53、高さ 76.95（取付座を含む） |
| 取付 | 推力軸から取付面まで 40.85。取付座 36.6×22.6、めねじ 4-M3（ピッチ 30×15） |
| ケーブル | 径 7 mm、長さ 150 cm |
| 使用環境 | 淡水・海水 |
| 回転方向 | CW・CCW を選べる |
| ESC | 別体（付属セットあり）。PWM 1〜2 ms、1.5 ms で停止 |
| 価格 | 5,088 円（ESC なし）。取付ベースは別売 1,511 円 |
| 3D データ | メーカー配布の IGES を取り込んで CAD に使っている |

- 仕様表が 2 種類あり、届く個体がどちらかは注文時に確かめる。設計は低い方（8 A 版）で成り立たせ、
  電源は 12 A 版でも足りる容量（8 基で 96 A）を見込む。
- 取付ねじの軸方向ピッチ 30 は、寸法図の「30」をそう読んだ値である。配布 3D データの取付座の長さ 36.6 と整合するが、
  図面に明示は無い。板に穴をあける前に現物で確かめる。
- **耐水深は販売ページに記載が無い。** 設計水深 100 m で使えるかは、メーカーへの問い合わせか耐圧試験で確かめるまで未確認として残る。

比べた機種: ApisQueen U01（淡水専用、17 A）、Diamond Dynamics TD1.2（1.2 kgf、13 A、52 米ドル）。
U01 は海で使えず、8 基で 136 A になる。TD1.2 は推力あたりの電流と価格で U2 Mini に劣る。

## 3. 配置

座標は X = 前、Y = 上、Z = 右舷、原点 = 耐圧筒の中心。

| 群 | 位置 | 推力方向 | 取付先 |
| --- | --- | --- | --- |
| 垂直 4 基 | (±170, 0, ±155.85) | 上 | 側板の外面 |
| 水平 4 基 | (±170, −145.85, ±56) | 水平面内で前後軸から 45° | 底板の下面 |

- 垂直 4 基を側板の外側の四隅に置き、ロールとピッチの腕を長く取った。
- 水平 4 基は 45° の X 字配置で、前後・左右・ヨーを独立に出せる。噴流は側板の窓を抜ける。
- 垂直スラスタの吸込み・吹出しの上下に、底板と側板が掛からない。
- アセンブリでは、水平スラスタの推力軸をレイアウトスケッチの線に一致させて拘束している。垂直スラスタは基準平面 3 枚に一致させている。
- 板側の取付穴（Ø3.4 キリ）はトップアセンブリの穴フィーチャで、底板と側板に反映している。

## 4. 制御力の見積り

計算は [thruster_allocation.py](../../../analysis/thruster_allocation.py) と [controllability.py](../../../analysis/controllability.py)。質量 16.4 kg、BG 23.0 mm、1 台の推力は正転 12.7 N・逆転 11.8 N（逆転比は仮の値）。

### 4.1 可制御性

| 項目 | 結果 |
| --- | --- |
| 制御行列 B（6×8）の階数 | 6。6 自由度を独立に制御できる。冗長度 2 台 |
| 条件数（モーメントを腕 0.2 m で力に換算） | 1.89。方向による出しやすさの偏りは小さい |
| 動的な可制御性（ホバリングまわりの線形モデル、12 状態、PBH 条件） | 12 / 12 |
| 1 台停止（8 通り） | すべて階数 6、動的にも 12 / 12 |
| 2 台停止（28 通り） | 16 通りは 6 自由度を保つ。水平どうし・垂直どうしの 12 通りは 1 自由度を失う |

### 4.2 各軸で出せる最大値

ほかの 5 成分を 0 に保ったまま出せる値（線形計画法による上限）。

| 軸 | 正常時 | 1 台停止の最悪 |
| --- | --- | --- |
| 前後 Fx | +36.1 / −33.3 N | 16.6 N |
| 上下 Fy | +48.2 / −44.5 N | 22.3 N |
| 左右 Fz | ±33.2 N | 15.9 N |
| ロール Mx | ±7.34 N·m | 3.67 N·m |
| ヨー My | ±7.52 N·m | 3.76 N·m |
| ピッチ Mz | ±8.00 N·m | 4.00 N·m |

### 4.3 姿勢保持

- 復原モーメントの最大値は W·g·BG = 3.69 N·m。正常時はロール 2.0 倍、ピッチ 2.2 倍のモーメントを出せるので、任意の姿勢を保持できる。
- 垂直スラスタが 1 台止まるとロールは 3.67 N·m（復原の 0.99 倍）になり、保持できる傾きは約 83° までになる。1 台故障でも任意姿勢を保つには BG を 22.8 mm 以下にする。
- 最大角加速度はロール約 3950 °/s²、ヨー約 1200 °/s²、ピッチ約 1360 °/s²。慣性は部品を点質量とみなした値で、付加質量と抵抗を含めていない。実機はこれより遅い。
- 振り子としての固有周期はロール 1.04 秒、ピッチ 1.86 秒（同じ近似）。
- 8 台同時最大の電流は 64 A。
