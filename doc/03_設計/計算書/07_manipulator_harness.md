## 2. マニピュレータ

### 2.1 サーボ

設計水深 100 m で使える定格のサーボとして、ROVMaker の水中サーボ RM-SV-40 を使う。
一般の防水サーボ（IP68）は水深の定格ではないので使わない。
当初選んだ MOT-SERVO-34KG-DIGITAL-120DEG は公式ストアで在庫切れだったため、在庫のある RM-SV-40 に置き換えた（2026-11-25）。

| 項目 | 値（AliExpress「AI Robot Store」の商品ページの仕様表・寸法図） |
| --- | --- |
| 型式 | RM-SV-40（Angle version） |
| 使用水深 | 300 m（商品ページに加圧試験の記録あり） |
| トルク | 動作 1.5 N·m、ピーク 3.0 N·m |
| 動作角 | ±175°（制御信号 PWM 500〜2500 µs、中立 1500 µs） |
| 電圧・電流 | 定格 12 V、ピーク 4.3 A |
| 質量 | 360 g |
| 外形 | 本体 66（軸方向）×55.5×35.5。片側に出力円板 Ø30、反対側に従動軸 Ø30、全長 80.1。上面にケーブルグランド（全高 69） |
| 出力円板・従動軸の取付 | 4-M4 深さ 5、PCD 24 |
| 本体の取付 | 上面・下面に 6-M3 深さ 5 ずつ（幅方向ピッチ 18、従動軸側の端から 10・25・40） |
| ケーブル | 径 4 mm、長さ 0.7 m |
| 価格・在庫 | 28,206 円、在庫 985 個、配達 12/2〜12/10 の表示（2026-11-25 確認） |

置き換えで変わった点と、その対処は次のとおり。

| 変わった点 | 対処 |
| --- | --- |
| 定格電圧が 12 V（旧型式は 12〜28 V） | バッテリ 4S（13〜17 V）から 12 V を作る DC-DC コンバータを耐圧容器内に追加する |
| ケーブルが 0.7 m（旧型式は 1 m）、径 4 mm | 後端蓋まで届かないので途中で延長し、接続部を樹脂で封止する。ペネトレータは WLP-M10-4.5MM-HC に変える |
| 本体が高い（アーム板の上面から 55.5、グランドの上端まで 69） | 本体上面は筒の中心から 29.5 下、グランドの上端は 16 下になる。観察窓（開口 Ø80）の下側の視野に入る |
| めねじの深さが 5 mm | アーム板・可動爪の板厚 10 に対し、ねじ込み 4 mm になる長さ（M3×14、M4×14）を使う。長いねじを使わない |
| トルクは同等（ピーク 3.0 N·m、旧型式 3.3 N·m） | 爪の寸法は変えない |

### 2.2 構成

| 部品 | 材質・素材 | 役割 |
| --- | --- | --- |
| アーム板 | HDPE t10 | 底板の上に M5×4 で固定する T 字形の板。前半にサーボを載せて下から 6-M3 で止め、先端が固定の下あごになる |
| 可動爪 ×2 | HDPE t10（左右共通） | サーボの出力円板と反対側の従動軸に 4-M4 で付ける。サーボの回転でアーム板の先端へ向けて閉じる |
| つなぎ棒 | 寸切 M5×125 | 左右の可動爪の先端をつなぎ、物を下あごへ押さえる |

- 加工品はフレームと同じ HDPE 板からの切り出しだけで、追加の加工方法は無い。
- アーム板は前の筒受けの下部のくぐり穴を通る。後半を幅 72 に絞ってあるのは、底板を貫く水平スラスタの取付ねじを避けるため。
- 爪先での押さえ力は、動作トルク 1.5 N·m を回転中心からつなぎ棒まで 90 mm で割って約 17 N（1.7 kgf）、ピーク 3.0 N·m で約 33 N。
- サーボは質量 0.36 kg で機首側に付く。前後の釣合いはバッテリの位置で取る（[03_buoyancy_balance.md](03_buoyancy_balance.md)）。

## 3. ハーネス

### 3.1 貫通と本数

| 用途 | 本数 | ケーブル径 | ペネトレータ |
| --- | --- | --- | --- |
| スラスタ | 8 | 7.0 | WLP-M10-7.5MM-HC（PCD 90 に等配） |
| サーボ | 1 | 4.0 | WLP-M10-4.5MM-HC（中央 PCD 30） |
| テザー | 1 | テザーの径による | 同上の列 |
| ベントプラグ | 1 | — | 同上の列。気密試験に使う |

### 3.2 経路

経路は [build.py](../../../src/uwd01/build.py) の `harness_paths` に点列で書いてあり、CAD では 3D スプラインに沿った丸断面で作図している。

1. スラスタから側板の外面へ出る。垂直スラスタはモータ下端から、前の水平スラスタは前の噴流窓を抜けて出る。
2. 側板の外面に沿って、片舷ずつ束にして後ろへ送る。束の中の位置は 1 本ずつ決めてある。
3. 後ろの噴流窓から機体の内側へ入る。
4. 後端で折り返して、後端蓋のペネトレータに入れる。折り返しの位置は X = −302 で、側板の後端（−320）の内側に収まる。

後ろの水平スラスタは底板の下から直接後端へ回す。サーボのケーブルは右舷の束に入れる。

### 3.3 固定

| 固定点 | 方法 |
| --- | --- |
| 側板の外面、片舷 4 か所（X = ±100、±205） | 穴 Ø5.5 を上下 2 個（Y = −66 と −92）あけ、結束バンド（幅 4.8）を通して束を留める |
| 後端の折り返し | 端蓋の抜け止めを兼ねる下側の横通しボルトに結束バンドで留める |
| テザー | 引張りを端蓋に掛けない。フレームに張力止めを付ける（未作図） |

- 側板の長さ ±320 は、ペネトレータが端蓋の外面から 25 突き出すこと（配布 CAD で確認）と、
  径 7 のケーブルの曲げ半径 約 35 から決めた。
- スラスタのケーブルは 150 cm あり、最長の経路（前の垂直スラスタ）でも足りる見込みだが、束ねた実長は CAD の経路長で確かめる。

## 4. 残る確認事項

| 項目 | 内容 |
| --- | --- |
| サーボの寸法 | 販売ページの寸法図から作図した。グランドの太さは目測。現物で取付穴とグランド位置を確かめる |
| サーボのケーブル延長 | 接続部の封止方法と、延長後の全長を現物合わせで決める |
| サーボの電源 | 12 V の DC-DC コンバータの品番と置き場所を決める |
| 視野 | カメラの位置と画角を決め、サーボとグランドが写り込む範囲を確かめる |
| 可動爪の剛性 | HDPE t10 の爪は曲がりやすい。重い物をつかむなら POM かアルミにする |
| ケーブルと噴流 | 側板の外面の束が垂直スラスタの吸込みに掛からない位置かを実機で見る |
| テザーの張力止め | 未設計 |
